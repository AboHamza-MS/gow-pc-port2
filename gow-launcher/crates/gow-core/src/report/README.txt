GOD OF WAR (2005) PC PORT: SESSION REPORT

Attach this file to the bug report on GitHub. Read what is inside first: it is all plain text.

Inside
  report.json    the launcher version, the PC (system, processor, memory, graphics), the settings, the
                 installation (sizes, dates, the checksum of the game program, the CRC of the game file),
                 the environment the game gets, and what the launcher knows about the last session
  logs/          the launcher's logs: the game log, the previous one, and the install, optimization,
                 update and kit logs
  markers.txt    the notes you wrote with "Mark a problem"

Never inside: the disc image, the game file or its data, saves (memory card), recorded graphics
microcode, textures, shader caches, screenshots, passwords.

Removed from every text before it was written here: the folders of the installation, the launcher's
data, the temporary files, your home folder, and the folders of the disc image and the game (shown as
<INSTALL>, <DATA>, <TEMP>, <HOME>, <ISO_DIR>, <GAME>, <RUNNER>, <LAUNCHER>), your Windows or system
user name (<USER>) and the computer name (<PC>), and the RetroAchievements user (shown only as set
or not).

Limits: the removal is by text match. It does not catch short 8.3 names (PROGRA~1), URL-encoded paths
or a name written with different letters. A word that happens to be the same as your user name is
replaced too. Notes you wrote yourself are kept as typed (apart from those replacements): do not put
personal information in them. Look through the files before you attach the report.

If the game was running when the report was made, the report is partial: the game log was still
being written.

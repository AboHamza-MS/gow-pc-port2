# ps2xRuntime

The runtime library that executes the recompiled game. It is linked into `ps2EntryRunner`, whose binary is
`gow-2005[.exe]`.

What lives here:

- `src/lib/ps2_runtime.cpp`: runtime construction, memory map, thread bring-up and the frame loop.
- `src/lib/Kernel/`: kernel and syscall services, SIF, DMA, pad, memory card, MPEG, timers.
- `src/lib/gs/`: GS frontend (GIF tags, vertex assembly, register state) and the renderer: `gpu/gs_hw_backend.cpp`
  (native OpenGL render targets) wrapped by `gs_threaded_backend.cpp`; presentation in `gs_host_present.cpp`.
- `src/lib/vu/`, `src/lib/ee_ref/`, `src/lib/vu_pcsx2/`: VU1 execution (compiled blocks and interpreter) and the
  reference interpreters used for verification.
- `src/lib/gow_*.cpp`: the PC features (window, widescreen, cheats, target lock, agile combat, OSD), wired by
  `gow_integration.cpp`.
- `src/game/`: the game's own function overrides; `gow_overrides.cpp` binds each address.
- `src/runner/`: the C++ generated by `ps2_recomp`. The installer writes it here; **never edit it by hand**.
- `include/`: runtime headers, plus the generated headers placed next to them.
- `third_party/`: xxHash, stb, bcdec, libmpeg2, rcheevos (see [`../../../docs/THIRD_PARTY.md`](../../../docs/THIRD_PARTY.md)).
